Local inference · Open-source model

Run the AI engine on your PC.

This companion engine uses CogVideoX-2B to generate short text-to-video clips locally. It does not call a paid hosted inference API and needs no API key. Your PC downloads the public model weights and then performs generation itself.

EARLY ACCESS · LOCAL COMMAND-LINE RUNNER

What you need

Windows 10/11, Python 3.11, NVIDIA GPU with CUDA support, current drivers, stable internet for the first download, and plenty of free disk space.

What to expect

A short AI-generated clip saved as MP4. Runtime and quality depend on GPU, memory, prompt, and settings. This is not guaranteed to match commercial services.

Install on Windows

  1. Install Python 3.11 and update your NVIDIA drivers.
  2. Use the official PyTorch installation selector to install a CUDA-enabled build compatible with your PC.
  3. Open the local-engine folder on GitHub and download its files, or clone the repository.
  4. Run setup_windows.bat, then activate the virtual environment and install the requirements:
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Generate your first clip:

python generate.py --prompt "A cinematic aerial shot over a futuristic city at sunset, dramatic clouds, smooth camera movement"

The first run downloads the model weights from Hugging Face. It may take a long time and use many gigabytes of storage.

Hardware and compatibility

CogVideoX is a large video-generation model. Memory needs vary substantially by precision and optimization; sequential CPU offload and VAE slicing/tiling are enabled in this starter, but they can slow generation. If your PC has no compatible NVIDIA GPU, use the browser motion-graphics editor instead. Android browsers cannot directly run this Python GPU engine.

The local engine is a separate command-line program and is not yet connected to the website's Generate button. GitHub Pages cannot run Python or use your PC's GPU by itself.

Privacy and licensing

Prompts are passed to the local model process. The app code does not call a paid inference service. The first model download connects to the public model host. Review the model card and license before using or distributing generated content.
